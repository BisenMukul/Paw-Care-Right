## 3. Tagging discipline for the notes (binding — the test enforces it)

- Every actionable step is a markdown task line beginning `- [ ] ` at column 0.
- Every such line carries **exactly one** tag, immediately after the checkbox, as literal bold text: `**[FOUNDER]**` or `**[AUTOMATED-READY]**`.
  - `[FOUNDER]` = requires a human, a console login, a legal/identity/payment action, or a secret this container cannot hold.
  - `[AUTOMATED-READY]` = already scripted/documented here; the line **must** contain at least one backtick-quoted runnable command.
- Anything that is neither (e.g. "at T106 flip `submit.production.android.track` to `production`") goes in prose, **not** in a `- [ ]` line, so the two-tag invariant stays exact.
- No invented identifiers anywhere: no ASC app id, no Apple Team ID, no service-account email, no project UUID other than the one already in `app.config.js`. Placeholders are written as obviously-fake angle-bracket tokens (`<asc-app-id>`, `<apple-team-id>`, `<path-outside-repo>/play-service-account.json`) — low-entropy, never real-looking.
