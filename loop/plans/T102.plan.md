**Universal evidence-capture format — every single lookup produces one row, no exceptions:**

```
| candidate | source | exact query string or URL | UTC date+time of lookup | verbatim result summary (or "0 results" / "BLOCKED: <http status / captcha / login wall>") | preliminary screen verdict |
```

Hard rules for the research agent:
- **Never** write a verdict without a URL and a timestamp in the same row.
- If a source is captcha-walled, login-walled, rate-limited, or 4xx/5xx → the cell is `BLOCKED: <reason>` and the verdict is `NOT-VERIFIED`. **Never** substitute recollection or a secondary blog/summary for a primary register. A blocked lookup is a legitimate, expected outcome and must survive into the final doc.
- Quote result titles/owners **verbatim**; do not paraphrase an owner name or a goods/services description.
- Record nothing that looks like a credential, key, or token.

### 2.1 App store searches (per candidate)
Run and record all of these:
- Apple, machine-readable (preferred, returns JSON): `https://itunes.apple.com/search?term=<urlencoded>&entity=software&limit=50&country=US`, then repeat with `country=IN`, `country=GB`, `country=DE`. Terms per candidate: exact display name; plus for the primary also `bombay pet`, `bombaypetcompany`, `bombay pet company`.
- Apple, human-readable cross-check: `https://apps.apple.com/us/search?term=<urlencoded>`.
- Google Play: `https://play.google.com/store/search?q=<urlencoded>&c=apps&hl=en&gl=US` and `&gl=IN`. Same term list.
- Capture per hit: **app name, developer/seller name, bundle/package id, storefront**. Explicitly flag any hit whose name contains the candidate as a whole word, and any pet-category hit at all.
- Also record: does any app already use the package id `com.bombaypetcompany.app` (search Play for `id=com.bombaypetcompany.app` via `https://play.google.com/store/apps/details?id=com.bombaypetcompany.app` — a 404 is the desired evidence and must be recorded as such).

### 2.2 Trademark registers (per candidate)
Relevant Nice classes to screen: **9** (downloadable software), **42** (SaaS), **35** (advertising/retail), and — as an explicit *negative* check — **44** (which includes veterinary services; we are deliberately **not** in class 44, and the doc must say so).
- **USPTO** — `https://tmsearch.uspto.gov/search/search-information` (TESS is retired; use the current Trademark Search UI, and TSDR `https://tsdr.uspto.gov/` for any live hit's status). Search each candidate as a word mark; for the primary, also search bare `BOMBAY` restricted to classes 9/35/42/44 and note the well-known unrelated-class registrations (record verbatim owners/classes; do not assert legal conclusions).
- **EUIPO** — `https://euipo.europa.eu/eSearch/#basic/1+1+1+1/100+100+100+100/<candidate>`.
- **India (CGPDTM)** — Public Search of Trade Marks `https://tmrsearch.ipindia.gov.in/tmrpublicsearch/` (wordmark search, classes 9/35/42/44). This is the **S1 substitution for the stale card's Algeria INAPI** — note the substitution in the dossier header too.

### 2.3 Domains (per candidate)

## 4. Where the listing strings live — DECISION (D1)

**Decision: `docs/store-listing.md` only. They are NOT added to `apps/mobile/store-assets/marketing-strings.ts`.**

Justification:
- T100 put screenshot captions in `marketing-strings.ts` because a **program consumes them** (`compose-screenshots.ts` renders them into PNGs). Listing copy has no code consumer — it is typed by a human into App Store Connect / Play Console.
- `apps/mobile/__tests__/store-marketing-strings.test.ts:68-70` pins `shots` at exactly 8 entries; adding listing copy there would either break that pin or bolt an unrelated shape onto a screenshot-caption module.
- Two homes = two sources of truth = a byte-pin obligation between doc and TS, for zero benefit. Single-sourcing in the doc, with the drift guard reading the doc directly (the `release-runbook-doc.test.ts` precedent), gives identical detector coverage with one source.
- The one genuinely shared string — the disclaimer — is **not** duplicated: it is asserted against `vetDisclaimerLine(APP_DISPLAY_NAME)`, so it still has exactly one source of truth (`packages/types`).
