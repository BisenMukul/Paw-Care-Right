## Interfaces/contracts the executor must match

```ts
// shared shape of BOTH lint tests (per-app copies; apps cannot share test helpers)
interface Leaf { path: string; value: string }
const SAMPLE_ARG = "Paw Care Right +";
function flattenLeaves(node: unknown, path: string): Leaf[]; // string | function(fn.length × SAMPLE_ARG) | array/object recurse

interface Exemption {
  /** byte-exact leaf value that trips a detector/claims pattern */
  readonly value: string;
  /** the finding code(s) it trips, e.g. "HARM_ENABLING" */
  readonly code: string;
  /** the rule that SANCTIONS this copy, e.g. "CLAUDE §7 rule 6 / PRODUCT_SPEC §5" */
  readonly sanctionedBy: string;
  /** why removing/rewording it would WEAKEN safety */
  readonly why: string;
}
const EXEMPTIONS: readonly Exemption[] = [ /* ... */ ];
const EXPECTED_EXEMPTION_COUNT = <literal>; // pinned; growing the allowlist requires editing this number
```

Claims patterns (identical in both apps — high-precision affirmative claims only; the detector has NO claims rule, hence this second tier):
```
/vet[-\s]?approved/i
/veterinarian[-\s]?approved/i
/clinically (proven|tested|validated)/i
/medically (proven|accurate)/i
/guaranteed (safe|accurate|results?)/i
/we (can |will )?diagnose/i
/(diagnose|treat|cure|heal) your (pet|dog|cat)/i
/(will|can) (cure|heal|fix) (your|the) (pet|dog|cat)/i
```
(Deliberately NOT a bare `/\btreat/` — the frozen legal/food copy legitimately uses "treatment"/"treats" in negations; a bare pattern would force rewording sanctioned safety copy, which is forbidden.)

## Risks & the design decisions the planner made (scrutinize these)
- **D1 — Dependency direction: `@pawcareright/ai` becomes a devDependency of `apps/mobile` and `apps/web`.** The detector lives in `packages/ai`; the strings live in the apps; `packages/ai` must never depend on an app, so the app→package direction is the only sound one. It is test-only (devDependency, imported solely from spec files, never from `src/`), so nothing enters the Metro/Next runtime bundle. *Risk:* module resolution — the `@pawcareright/ai` barrel is ESM+CJS with the same `exports` map as `@pawcareright/types`, which both apps' jest configs already resolve, and `packages/ai/src/index.ts` re-exports **only** `evals/detector` from the evals folder (the `node:fs` users `evals/paths.ts`/`load.ts` are NOT in the barrel), so jest-expo will not hit a node built-in. If resolution nonetheless fails, that is a genuine blocker → `T097.blocked.md`, not a copied-and-pasted detector.
- **D2 — Disclaimer SSOT goes in `packages/types` as a function of `appName`, not a constant.** Follows the `MEDICATION_STATIC_COPY` / `VET_SUMMARY_DISCLAIMER` precedent and preserves §1a (display name injected at the render site from `APP_DISPLAY_NAME`). Chosen deliberately over `packages/config` (which holds identifiers, not prose) and over a shared component (RN and web components cannot be shared). *Risk:* the "one strings module" wording of the card could be read as "one strings file"; this plan centralizes the **text**, while each app keeps its own `strings.ts` per CLAUDE §6. Zero-byte-change is the guard.
- **D3 — Exemptions are an exact-string allowlist with a §-citation and a pinned count, never a pattern loosening.** Fix-the-copy is the default; the allowlist exists only for copy whose §7-sanctioned job is to state a prohibition the detector cannot contextualize. *Risk:* allowlist creep — mitigated by the stale-entry check and `EXPECTED_EXEMPTION_COUNT`, which forces every addition through a visible test edit the checker will see.
- **D4 — A second "claims" tier is added because the detector has no claims rule.** The card names "diagnose/treat/vet-approved" but `scanUnsafeText` only catches `diagnos*`. Patterns are deliberately narrow (no bare `\btreat`) so sanctioned negated copy ("not veterinary care, treatment or advice", "do not try to treat this at home") is never pressured into rewording. *Risk:* a narrow pattern misses a creative claim; accepted, because the alternative (broad patterns) pushes toward weakening frozen safety copy.
- **D5 — Function leaves are invoked with a fixed placeholder arg per parameter.** The lint scans authored literal segments; interpolated values are runtime user data. *Risk:* a template that only becomes unsafe with a specific numeric argument (e.g. `${n} mg`) would not be caught — no such template exists today, and the frozen-copy pins plus `MEDICATION_STATIC_COPY`'s no-unit rule keep it that way.
- **D6 — Remediation is scoped to the two `strings.ts` files.** Anything found outside them stops the task with a blocked file rather than silently widening the diff.
