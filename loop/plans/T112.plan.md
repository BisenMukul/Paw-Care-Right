## 11. Risks & the decisions the planner made (top 3 for an S card)

**R1 — ICE scores are judgment, and the card asked for data we do not have.** *Decision:* keep the scores but (a) make the rubric explicit and the arithmetic machine-checked (T-04), (b) force a deterministic order (T-05), (c) cap Confidence at 5 for every user-behaviour-dependent row (Rule C, T-08), and (d) put an honesty section first and a banned-attribution scan over the whole doc (T-13/T-14). *Residual:* the individual integers remain unfalsifiable — the checker should scrutinise whether any single row's Confidence is implausibly high, and whether §1 reads as a genuine disclosure rather than boilerplate. The alternative (refuse to score until beta data exists) would fail the card's explicit "scored ICE / ≥15 items" AC, so it was rejected.

**R2 — Where the drift guard lives.** *Decision:* `apps/mobile/__tests__/backlog-doc.test.ts`. `docs/BACKLOG.md` is a repo-level doc with no owning code workspace, and every existing repo-level doc guard in this codebase lives exactly there (`release-runbook-doc`, `store-listing-doc`, `checkpoint-c3-notes-doc`, `store-assets-doc`, `state-audit-doc`), which also gives free access to `scanUnsafeText` with no new dependency. The rejected alternative was `packages/data/src/qa/` — that idiom is for *generated-from-data* docs (`dataset-audit.md` is byte-pinned to a renderer), which this hand-written doc is not.

**R3 — Both drift guards parse markdown, so they are brittle in one direction and blind in another.** The §3 table parse and the `PRODUCT_SPEC §10` `·`-split will break on reformatting (intended — that is a drift guard), but **no test can detect a *wrong* score, a mis-transcribed rationale, or a fabricated Source line number that happens to match the citation regex.** T-07 checks citation *shape*, not truth. *Mitigation:* step 5.2 requires re-opening each cited line, and the checker should independently resolve a sample of `loop/journal.md:NNNN` citations against their claims — this is the same residual the T102 review recorded (a drift guard cannot detect fabricated evidence; accuracy rests on checker/human review).
